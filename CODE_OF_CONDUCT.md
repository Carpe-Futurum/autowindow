# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and considerate in issues, pull requests and discussions.
- Criticize code and ideas, not people.
- No harassment, insults, sexualized language or imagery, or publishing other people's private information.

This applies in all project spaces, and when someone represents the project elsewhere.

## Reporting

Report unacceptable behaviour to **dev@carpefuturum.nl**. Reports are read by the maintainers and kept
confidential. Maintainers may remove comments, close threads, or block someone from the project, depending on
what happened.
